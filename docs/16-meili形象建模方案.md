# #16 meili 形象建模方案（草稿 · 待讨论定稿）

> 状态：**草稿**。本文档所有"建议值/推荐方案"均为提案，标 🔲 的决策点需用户拍板后定稿。
> 已定稿约束（产品设计 §10.2，不重开）：3D 软低多边形 · 充气感 · 海洋系（柔和卡通着色 + 边缘光；参考：深海水族馆 × 罗小黑 × PEAK；单生物 ≤5 万面）；美术素材须含 Steam 商业发行权书面授权。

## 1. 目标

把占位模型（Soldier.glb，Mixamo 人形，11k 三角）替换为正式形象：**小水獭 meili**，并顺手完成两件挂账事项：

- **#28 倾听反馈物种化**：现在唤醒反馈是"跳跃 + 气泡 + 强制注视"的通用占位，要换成水獭自己的表达方式；
- **物种配置化**：现在 `src/main.ts` 硬编码加载 Soldier.glb；meili 落地时改为"物种配置表驱动"（与口癖进动物表的方案 b 同一条线），为将来海洋生物园多只生物铺路。

## 2. 形象设计：性格怎么变成样子

从已写定的角色档案（产品设计 §4.1）提炼视觉要素：

| 性格/设定 | 视觉化方案 |
|---|---|
| 收容所老员工、温暖可靠 | 体型圆润饱满（充气感的载体），站姿放松，尾巴大而蓬松拖在地上 |
| 好奇心强、盯着鼠标看 | **眼睛是重头**：大眼、高光点大；眉毛/眼皮骨骼做表情体系 |
| 口癖"美丽认为"（爱发表看法） | 说话时下颌开合 + 前爪比划小动作 |
| "把宝贝送给你"的物种行为 | 随身道具：**一枚贝壳**（挂胸前/抱在怀里），告别信物伏笔 |
| 水獭搓脸标志性动作 | 倾听期的招牌小动作（见 §5） |

配色建议：暖棕主体 + 奶油色脸/腹 + 海洋系点缀（贝壳粉、海藻绿小挂件）。🔲

## 3. 关键决策点

### D1：绑定路线 🔲 **推荐 A**

| | A. 人形直立绑定（Mixamo 兼容） | B. 四足写实绑定 |
|---|---|---|
| 形象 | 深海水族馆/罗小黑式直立坐姿，前爪当手 | 完全写实四足爬行 |
| 动画来源 | **Mixamo 全库直接可用**（idle/jump/wave/sit/dance/被拎…几百个） | 全部手做或程序化，成本约 ×10 |
| 倾听反馈 | 扭头正视 = 头部骨骼 + LookAt 程序控制，现成管线直接复用 | 四足抬头姿态需要专门调 |
| 代价 | 牺牲一点写实度 | 形象最"正确"但慢且贵 |

现有管线（GLTFLoader + Mixamo 动画 + 视线 LookAt）就是按 A 搭的；Soldier 换掉时管线零改动。**强烈建议 A**：meili 是"员工"不是"标本"，拟人直立也正好接住"被拎会扒手不安"这类人格化交互（产品设计 §7.3）。

### D2：动画清单来源 🔲 **推荐：Mixamo 打底 + 水獭招牌动作手做**

通用动作（idle×2-3 套、jump、wave、walk、被拎挣扎、sit、sleep）用 Mixamo 改；招牌物种动作（搓脸、翻石头、递贝壳、搓搓前爪听人说话）手做关键帧，数量控制在 6-8 个以内。

### D3：生产路径 🔲 **推荐分两段**

1. **原型段（本周可完成）**：AI 文生 3D（本机 model3d_generation 插件）出低模水獭 → 跑通"新模型进管线 + 动作映射 + 倾听反馈"全链路。不求美，求管线活。
2. **正式段（定稿后启动）**：三选一，需连同授权一起拍板：
   - 采购现成低模资产改水獭（Quaternius/KayKit 等 CC0 或付费授权，便宜快，要核 Steam 发行权条款）；
   - 外包定制（质量最高，周期 2-4 周，预算需谈）；
   - 自建 Blender 产能（长期最可控，短期最慢）。

### D4：性能预算目标值 🔲 **建议：≤1.5 万三角 / GLB ≤5MB**

已定上限 5 万面，但 #36 残留实测显示：Soldier 11k 三角已是空闲期 renderer 8.6% 的主要固定成本之一。Q 版水獭解剖细节少，**8k–15k 三角视觉完全够用**，顺手把待办 #40 的"换低面数模型"一并解决。纹理单张 1024 atlas（风格化低模不需要更高）。

## 4. 接入方案（工程侧）

物种配置化，一条配置一个生物，将来加生物 = 加配置 + 加资源：

```
species/meili.toml        # 名称、口癖、模型路径、默认缩放、倾听参数(N 秒等)
models/meili.glb          # 网格 + 骨骼 + 全部动画 clip
src/main.ts               # 硬编码 Soldier 加载 → 读 species 配置
```

- 动画仍走 `gltf.animations` 按名字索引，**clip 命名约定先行定死**（`idle_a / idle_b / jump / wave / listen / petted / held…`），Mixamo 原名进配置映射表；
- 倾听参数（注视时长、倾听期小动作）进 species 配置，不硬编码——#28 本来就要按物种分化；
- 技术选型：TOML 热更机制 #34 已就绪，species 配置直接复用。

## 5. 倾听反馈物种化设计（水獭版，替换 #28 占位）

时序（现有 MAX_LISTENING=12s 上限不变）：

1. **被叫到（0–0.3s）**：当前动作 → 抬头，正脸转向用户。LookAt 权重 200ms 缓入；尾巴有一个小摆动（"诶？"）。
2. **倾听期（0.3–2.5s）**：招牌动作——**歪头 + 前爪搓两下**（水獭搓脸习性），眼睛眨 1-2 次。此间身体其余部位静止。
3. **用户持续说话（>2.5s）**：切换坐姿认真听：偶发点头、耳朵微动、继续眨眼；转写就绪随时打断进入回复。
4. **超时/结束**：LookAt 权重缓出，回到被打断的动作。

与占位的差别：现在是"跳一下 + 气泡 + 硬切注视"；正式版无跳跃（水獭不蹦蹦跳跳应答，她稳重），动作全部由骨骼动画驱动，注视只是其中一层。
