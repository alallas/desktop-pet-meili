# 《潮间带》技术架构文档

> 状态：v0.1（随 M0 预研结果迭代）
> 上游文档：《产品设计.md》v1.0。本文档只讲"怎么实现"，产品语义以设计文档为准。

---

## 0. 架构原则

1. **本地优先，离线完整**：无网、无 API key 时，陪伴/照顾/游戏循环全部可用（产品文档 §1 商业模式）。
2. **引擎与内容分离**：运行时只写一次；每只生物是一个内容包（产品文档 §9）。第一只生物 meili 即按内容包格式产出。
3. **性能预算先行**：桌宠 7×24 常驻，预算见 §7，超预算的功能降级或砍。
4. **隐私默认安全**：数据出机必须过用户可见的闸门（§8）。

## 1. 总体架构

**Tauri 2.x（Rust 系统层 + WebView 引擎层）**，Windows 优先，macOS 后期补系统层。

```
┌────────────────────── Tauri App ──────────────────────┐
│                                                        │
│  ┌──────────────────┐   IPC(事件/指令)   ┌───────────┐ │
│  │  Rust 系统层      │ ◄──────────────► │ WebView    │ │
│  │  src-tauri/       │                  │ 引擎层     │ │
│  │  ·事件采集        │                  │ src/       │ │
│  │  ·感知管道(截屏)  │                  │ ·行为引擎   │ │
│  │  ·语音管线(ASR/   │                  │ ·表现层    │ │
│  │  唤醒/TTS/云通道) │                  │  (Three.js)│ │
│  │  ·SQLite          │                  │ ·游戏系统   │ │
│  │  ·Steam 集成      │                  │ ·内容包加载 │ │
│  └──────────────────┘                  └───────────┘ │
│  ┌────────────────────────────────────────────────┐  │
│  │ 本地模型运行时（独立 sidecar 进程，按需启动）      │  │
│  │ llama.cpp(GGUF) · sherpa-onnx(ASR/VAD/唤醒)     │  │
│  └────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

分层职责一句话：**Rust 层负责"感知世界与说话的能力"，WebView 层负责"性格与表现"，模型 sidecar 负责"思考"。**

## 3. 模块划分

### 3.1 事件采集器（event-collector，Rust）
统一输出标准化事件到事件总线：

| 事件源 | 实现 | 频率 |
|---|---|---|
| 前台窗口标题/进程名 | GetForegroundWindow + GetWindowThreadProcessId | 事件驱动 + 1Hz 校验 |
| 性能指标 | sysinfo crate | 1Hz，带阈值+滞回+冷却（产品 §7.2） |
| 电源 | 电池状态/充电中 | 1Hz |
| 音乐播放 | Windows SMTC（曲目/歌手/状态） | 事件驱动 |
| 空闲时长 | GetLastInputInfo | 1Hz |
| USB/蓝牙插拔 | WM_DEVICECHANGE | 事件驱动 |
| 网络 | 连通性检测 | 0.2Hz |
| 锁屏/解锁 | 会话状态事件 | 事件驱动 |
| 全局鼠标位置/按键 | WH_MOUSE_LL 低级钩子 | 事件驱动 |
| 自窗口位置 | WebView 可读 window.screenX/Y | 边缘感知（攀爬一期） |
| 前台窗口位置/尺寸变化 | SetWinEventHook(EVENT_OBJECT_LOCATIONCHANGE) | 事件驱动；支撑"坐在窗口上"的摇晃/跌落/认窗 |
| 音频回环（节拍） | WASAPI loopback + onset 检测 | 仅音乐播放时开启；支撑跟节奏摇摆/哼唱 |

**红线**：剪贴板内容、键盘记录不提供任何事件（产品 §7.1）。

### 3.2 感知管道（perception，Rust）
产品文档 §6 的实现：
1. **触发器**：执行截屏四规则（稳定 30s / 目标关联 / 冷却 / 时段）；
2. **脱敏**：本地窗口枚举 → 命中黑名单进程（银行、聊天、支付）或检测到密码控件（UIA）→ 跳过或裁剪；
3. **分析**：截帧送本地 VLM，输出场景分类标签（工作/学习/娱乐/会议/游戏…）+ 置信度；
4. **写入**：情境记忆表（时间戳 + 场景 + 前台应用），供四道闸与目标账本消费；
5. **透明**：每次分析写隐私日志 + 轻提示事件。
隐私档位实现：沉默/默契/明说三档只是触发器与评论生成器的参数。

### 3.3 语音管线（voice，Rust 主导）
```
常驻:  麦克风 → [唤醒词检测] ──命中──► 回应事件(动画先行, <100ms)
倾听:  麦克风 → VAD 断句 → ASR 流式转写 → 意图路由
路由:  ├─ 简单指令/调节/媒体控制/应用启停 → 本地规则直接执行
       │   （媒体键模拟 / SMTC 状态 / 主音量 / Shell 启动 / WM_CLOSE 礼貌关闭）
       ├─ 日常对话/评论   → 本地小模型(人设 prompt + 口癖注入)
       └─ 深聊/复杂问答   → 云端 BYOK(流式)
输出:  文本 → TTS 流式 → 音频播放(边生成边播, 首句 <1s)
打断:  播放中命中唤醒词 → 立即停(<200ms) → "嗯?"
超时:  VAD 静默 8–10s → 退出倾听 + 告别语
```
- **人设一致性**：口癖、语气词、当前情绪状态随每次请求注入（本地云端同规则）；
- **按名路由**：喊「潮间带」→ 全体在场生物应答；喊生物名 → 单个；喊已离开生物名 → 在场朋友承接（产品 §5.1）；
- **云端降级**：无 key 或未配置时路由自动指向本地模型（产品"无 key 体验设计"）。

### 3.4 行为引擎（behavior，TS）
- **存在感光谱状态机**：L0–L4 档位 + 全局调节指令；
- **主动性四道闸**：待讲队列、冷却计时、心情信号推断（时段+负载+空闲）；
- **一日节奏**：按本地时间的作息编排；
- **事件映射执行器**：加载当前生物 `map.toml`，事件 → 反应（动画/台词/数值）；
- **防抖**：所有事件经阈值+滞回+冷却（5 分钟默认）；
- **性格参数**：驱动回访频率（产品 §12 #4）、被拎反应、鼠标策略等。

### 3.5 表现层（presentation，TS + Three.js）
- **窗口形态（M1-1 定案，2026-11-12）**：**桌宠小窗为主形态**——小尺寸透明无边框窗（跟随生物，如 300×400），性能符合 §7 预算，交互天然（拎起=拖窗口，窗外无关无需穿透切换）；**全屏覆盖层降级为"特效层"**——仅全屏演出（水花/粒子/告别仪式）时临时创建全屏穿透窗，演完即关，非常驻。气泡等小 UI = 窗内绝对定位溢出显示（透明窗可画出边界）；大件 UI（信件/图鉴）开第二个 UI 窗或临时拉大；
- **移动双通路（待办 #1 同案定案）**：①窗内移动（巡逻/走动/攀爬动画）= JS 内移动 3D 模型，60Hz 无系统调用；②窗口级移动（被拎起、坐别的窗口标题栏、拖动跟随）= Rust SetWindowPos 推进小窗（M0 实测 1.94ms/次）；移动前必须已是小窗尺寸（全屏窗只能挪 13px 的 M0 教训）
- **场景**：透明无边框小窗，生物 + 栖息环境元素（水面/岩石装饰）；
- **动画状态机**：状态（idle/移动/说话/睡觉/悬挂/告别…）→ AnimationMixer clip 切换 + blendshape 表情 + 口型；
- **视线系统**：光标坐标 → 头部/眼球 IK（3D 核心优势）；
- **边缘交互**：自窗口 screenX/Y 判定贴边 → 挂边/攀爬/安家姿态；
- **UI 覆盖层**：气泡、信件、档案、图鉴（DOM，随宿主语言）。

### 3.6 游戏系统（game，TS）
双数值曲线、照顾循环、告别周期调度器（七日脚本）、放归仪式、书信生成器（本地小模型 + 模板）、口碑系统、托管模式、图鉴/档案解锁。

### 3.7 内容包运行时（pet runtime）
加载/校验/热更新生物包（§5）；Steam Workshop 内容走同一校验管线（二期）。

### 3.8 数据层（SQLite）
```
creatures(生物档案+状态)   stats(信任度/生命力+变更流水)
goals(目标账本)            context_memories(情境记忆)
letters(信件/明信片)       collection(图鉴/校友录)
event_log(隐私日志)        settings(含隐私档位、API key 引用)
```
存档目录：`%APPDATA%/Chaojiandai/saves/`（接 Steam Cloud）。

### 3.9 云通道（cloud，Rust）
OpenAI 兼容抽象层；key 加密存储（Windows Credential Manager / Keyring）；**对话内容转发不落库**；预留订阅网关接口（同抽象层换凭证来源）。

### 3.10 浏览器扩展桥（M2，Rust + JS）
自研 Chrome/Edge 扩展：页面内识别地标元素（search-box / video-player / sidebar），经 native messaging 上报**坐标与通用标签**；支持读取视频标题与歌词可用性。**隐私红线：只上报坐标与通用标签，不上报任何页面内容**；扩展关闭即停止。分发：Chrome Web Store + Edge Add-ons，或本地 crx 侧载。

## 4. 关键数据流

**事件 → 反应**：采集器 → 事件总线 → 防抖 → 映射表（生物性格）→ 行为决策（四道闸）→ 表现层 + 数值变更。

**屏幕感知**：前台变化 → 触发器评估 → (脱敏) → VLM → 情境记忆 → 目标账本更新 / 待讲队列。

**书信**：触发（回访时机/捎话）→ 生成器（模板 + 本地模型 + 性格参数）→ 投递队列 → 下次启动或定时送达（"潮水速度"延迟是有意设计）。

## 5. 生物包格式（petpack v1）

```
pets/meili/
├── pet.toml          # 元信息：id/名字/物种/性格类型/音色
├── model.glb         # 模型 + 骨骼 + 表情 blendshape（≤5 万面）
├── anims/*.glb       # 动画 clip（idle/move/eat/talk/sleep/held/cling/farewell…）
├── map.toml          # 事件映射表：事件 → 反应（生物性格的主载体）
├── voice.toml        # TTS 音色参数/语速/口癖频率
├── dialogue/*.md     # 台词库（场景×事件×好感度分级）
└── archive/*.md      # 收容档案、信件模板、告别脚本
```

`pet.toml` 示例字段：`id, name, species, personality(好奇|黏人|捕猎…), revisit_style(恋家|标准|不羁), stat_curves(信任度/生命力曲线引用)`。

**加新生物 = 新增一个文件夹**；运行时不动一行引擎代码。

## 6. 隐私架构（产品 §6 的技术落地）

- 数据分级：**不出机**（屏幕截图原始内容、麦克风音频原始流、ASR 文本可配置）→ **出机**（BYOK 对话文本，用户可见）→ **本地日志**（截屏分析记录，可查可删）；
- 三档隐私 = 感知触发器与评论生成器的参数集，运行时一键切换；
- 敏感进程黑名单内置 + 用户可追加；密码控件检测（UIA）兜底；
- "别看我屏幕"指令 → 全局感知关闭 + 状态保持，随时可恢复。

## 7. 性能预算（硬指标）

| 项 | 预算 |
|---|---|
| 静默常驻 CPU | < 1%（事件驱动为主，轮询 ≤1Hz） |
| 对话峰值 CPU | < 15%（本地模型推理时段） |
| 常驻内存 | 引擎 + WebView < 300MB；本地模型按需加载，不常驻 |
| GPU | 核显可跑：单生物 ≤5 万面，toon 材质，无动态光影贴图 |
| 截屏分析 | 仅事件点触发，单次 ≤3s，分析完模型进程休眠 |
| 唤醒常驻 | 微模型常驻，内存 < 100MB |

低端机降级路径：关闭 VLM 截屏分析（保留元数据感知）、仅云端对话、降低渲染分辨率。

## 9. 主要风险与对策

| 风险 | 对策 |
|---|---|
| WebView 透明窗在多显示器/缩放比下异常 | M0 第一项验证；fallback 分层窗口 |
| 本地 VLM 延迟超预期 | 降分辨率/降频；兜底为"只记元数据不评论" |
| 唤醒词误唤醒率高 | M0 双方案实测；中文唤醒词定制训练 |
| 全局钩子被杀软误报 | 代码签名；钩子里不做任何记录类行为 |
| Workshop 内容包恶意脚本 | 内容包纯数据格式（无代码），加载前 schema 校验 |

## 9.1 商业授权审计结论（2026-11 核实）

- **代码层**：全部 MIT / Apache 2.0，可商用零费用（Tauri、Three.js、llama.cpp、sherpa-onnx、openWakeWord、silero-vad、ONNX Runtime、windows-rs、steamworks-rs 等）；
- **模型层**：SenseVoice-Small / Qwen3-4B / Qwen2.5-VL / Kokoro-82M / openWakeWord 模型均为 Apache 2.0 或 MIT，**IndexTTS 确认非商用已移除**；CosyVoice 2 列为 M0 授权复核候选；
- **义务**：随附第三方许可声明页（Apache 2.0 要求）；Steam 成本为 30% 分成 + 100 美元上架费；WebView2 免费引导安装；
- **新增红线**：外包/采购的美术模型与音效素材，合同必须含"商业发行权（含 Steam 分销）"——授权盘点须覆盖资产，不止代码与模型。

**复核检查点机制**（许可证低频变动，靠检查点防"换版本/换模型"风险，不靠重复审查）：
1. **M0 结束（选型冻结）**：逐组件复核锁定版本的许可证，以官方仓库 LICENSE 文件与模型卡为准（一手来源）；产出《选型锁定清单》；
2. **TTS 定版时**：实测选定后复核该模型授权（当前挂账待核：CosyVoice 2）；
3. **每次依赖升级**：CI 自动扫描（cargo-deny + npm license-checker，白名单 MIT/Apache 及变体，GPL/AGPL/CC-BY-NC 出现即拦截告警）；
4. **Steam 发布前**：发版 checklist 固定项——终检并生成随游戏附带的《第三方许可声明》内容，逐条对照官方 LICENSE 原文。
| 低端机跑不动本地模型 | 最低配置声明 + 云端强制模式（BYOK 变必选） |

## 10. M0 预研验证清单（按优先级）

1. Tauri 透明无边框窗：透明、点击穿透、置顶、多显示器、高分屏缩放 —— **透明/穿透/置顶已验证**（2026-11-11，GWL_EXSTYLE 实测含 LAYERED+TRANSPARENT+TOPMOST）；多显示器/高分屏缩放待实测
   - 本机构建环境备忘：无 MSVC（缺 Windows SDK 库），走 windows-gnu + rust-lld（配置在仓库根 `.cargo/config.toml`）；windres 资源编译依赖 `tools/m2w64*`（清华 anaconda 镜像 binutils+gcc），环境入口 `scripts/dev-shell.sh`，窗口验证脚本 `scripts/check-window.ps1`；**所有环境坑与解法见 `docs/踩坑与环境档案.md`**
