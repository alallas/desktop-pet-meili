# meili 物种档案（定种 · 待人工点A确认）

> 依据：产品设计 §4.1、docs/美术生产线.md §3。
> 本文件是全链"需求合同"：③④⑤ 阶段所有产出对照本文档验收。

## 是谁

- **物种**：小水獭（亚洲小爪水獭气质：体型小巧、爪子灵活）
- **名字**：meili / 美丽
- **口癖**："美丽认为……"（爱发表看法，回答常以它开头）
- **收容所角色**：「潮间带」的**老员工**——你是新来报到的管理员，她带你熟悉这里。
  温暖可靠、有主见，偶尔小得意。
- **性格关键词**：好奇心强（盯着鼠标看、对一切新事物凑近打量）、稳重不闹腾
  （被叫到是抬头看你，不是蹦蹦跳跳）、重感情（告别戏的情绪担当）

## 必保留的外形特征（验收红线）

1. 圆润饱满的充气感体型，站姿放松
2. **大而蓬松的尾巴**，拖在地上或微微翘起（水獭辨识度所在）
3. **眼睛是重头**：大眼、高光点大；眉毛/眼皮有可动骨骼支撑表情体系
4. **胸前一枚贝壳**（随身宝贝，"把宝贝送给你"与告别信物伏笔；阶段性可由抱着改为佩戴）
5. 前爪灵活（比划动作、搓东西、递物——口癖的视觉化载体）
6. 配色：暖棕主体 + 奶油色脸腹 + 海洋系点缀 🔲（待用户最终确认）

## 招牌动作清单（AI 做不出，阶段④手做关键帧）

| 动作 id | 场景 | 描述 |
|---|---|---|
| `special_rub_face` | 倾听期 | 歪头 + 前爪搓两下（水獭招牌搓脸，§倾听反馈设计） |
| `special_gift_shell` | 好感事件 | 解下胸前贝壳双手递出（告别前奏的伏笔动作） |
| `special_explain` | 说话 | 前爪比划 + 下颌开合（"美丽认为"的通用说话动作） |

## 通用动作需求（阶段④从 Quaternius CC0 库重定向）

`idle_a` / `idle_b` / `walk` / `jump` / `sit` / `sleep` / `petted`（摸头）/ `held`（被拎）/ `listen`（倾听基础姿态）

## 倾听反馈时序（验收标准，详细设计见美术生产线.md §3）

被叫到 0.3s 内抬头正视（LookAt 200ms 缓入）→ 0.3–2.5s 搓脸倾听期 → >2.5s 坐姿认真听 → 结束缓出回原动作。

## 资产类别与预算

主角生物：≤1.5 万三角、GLB ≤5MB、`--model p2` 四边面、`--no-texture` 裸几何。

短句、爱下结论、偶尔反问；语速清亮偏快（TTS 已定调）。
