## 0. 一页看懂

**架构一句话**：美术子 agent + 本机已装插件完成全部生产，零外部平台注册、零预算。

| 环节 | 工具 | 干什么 |
|---|---|---|
| 概念稿 | image_generation 插件 | 出图定风格（风格模板锁死，见 §4） |
| 生成网格 | model3d_generation 插件（**底层即 Tripo**，随 Kimi Work 订阅） | 文/图/多视图 → GLB，p2 四边面、可指定面数、`--no-texture` 裸几何 |
| 绑骨动画 | Blender（绑骨阶段才装，~300MB 走清华镜像；Windows 本机无预装） | 绑骨 + 动作重定向 + 手做招牌动作 |
| 标准化 | gltf-transform（npm 脚本） | 减面复核 / 剥纹理 / 统一朝向比例 / clip 重命名 |
| 入库 | 主 agent | species 配置 + 实机验收 |

**五阶段**：① 定种 → ② 概念稿 → ③ 生成网格 → ④ 绑骨动画 → ⑤ 标准化入库。
**用户只出场两次**：① 定种确认 + ② 概念图拍板。其余子 agent 自检 + 主 agent 实机把关。
**钱**：全程 $0。唯一潜在升级：插件质量长期不达标 → Tripo/Meshy 官方付费档 $20/月（红线决策）。
**周期**：主角生物从概念图拍板到实机动起来 2–4 个工作日（④占一半）；场景/物件每件 ≤半天。

## 1. 生产 SOP（子 agent 岗位说明书）

### ① 定种（人工点A）
产出 `species/<name>.concept.md`，全链"需求合同"：是谁（物种/性格/收容所角色）、
必保留外形特征、招牌动作清单（AI 做不出、须手做的物种专属动作）、资产类别。

### ② 概念稿（人工点B，唯一强制看图点）
按 `scripts/art-pipeline/style_prompt.txt` 出图；主角生物建议补同角色同姿态侧/背视图
（喂多视图生成）。**未经用户确认不进 ③。**

### ③ 生成网格（model3d_generation 插件）
固定套路：`--model p2`（四边面）+ `--face-limit N` + `--no-texture`。
自检：多视角渲染预览，查缺件/多指/比例崩/不像概念图。
小瑕疵用 `decimate` / `segment`+`complete` 修，修不好重生成（可无限重试）。
产出 `art/raw/<name>.glb`。

### ④ 绑骨动画（Blender，仅主角生物）
1. **绑骨**：Tripo 网格自动蒙皮三法全灭（坑 58），采用 `scripts/art-pipeline/blender_rig/rig_meili.py`
   程序化绑骨：手工骨表（18 根）+ 最近骨段距离 Top-4 蒙皮 + 解剖区域门。
   deform 门槛 = **动画实际角度下**不塌不裂（扭头 ≤25°、挥手臂 30°+胸协同 12°，再大必然穿插/撕裂，勿超）
2. **通用动作**：Quaternius CC0 动作库重定向（同为低模卡通风格，零成本；平台动作库为备选）
3. **招牌动作**：对照 concept.md 手做关键帧——全链唯一"纯人工"工序
4. clip 按附录命名约定落盘
5. Mixamo 路线**不做**（需 Adobe 账号，违反零注册红线）；本机 Blender 5.3 在
   `D:\Program Files\Blender Foundation\Blender 5.3\blender.exe`（用户已装，2026-11-25）

### ⑤ 标准化入库
gltf-transform 标准化 → `public/models/`；编辑器插件转台自检（对照 concept.md 打勾）；
主 agent 写 `species/<name>.toml`（模型路径、口癖、倾听参数、动作映射）并实机过交互清单；
CC0 素材凭证归档 `docs/licenses/`。

### 质量门与回退

| 关卡 | 不通过怎么办 |
|---|---|
| ③ 结构自检 | 插件内修 → 重生成 → 换文生描述重试 |
| ④ deform 不合格 | 换绑骨路线；三路线全败 → 降级"无骨骼程序动画"先上线，记入待办 |
| ⑤ 实机/风格 | 回 ③/④ 定位修；风格漂移回查 style_prompt.txt |

## 3. meili 首单（待办 #16 的执行内容）

### 形象要素（性格 → 样子）
圆润饱满体型（充气感载体）+ 大而蓬松的尾巴拖在地上（水獭）+ **眼睛是重头**
（大眼大高光，眉毛/眼皮骨骼做表情）+ **胸前一枚贝壳**（"把宝贝送给你"与告别信物伏笔）+
说话时下颌开合 + 前爪比划（口癖"美丽认为"的视觉化）。配色建议：暖棕主体 + 奶油色脸腹 +
海洋点缀。🔲 配色与贝壳道具待确认。

### 倾听反馈水獭版（替换现占位方案：跳跃+气泡+硬切注视）
1. 被叫到（0–0.3s）：抬头正脸转向用户，LookAt 200ms 缓入，尾巴小摆一下（"诶？"）
2. 倾听期（0.3–2.5s）：**歪头 + 前爪搓两下**（水獭招牌搓脸），眨眼 1–2 次，其余部位静止
3. 持续说话（>2.5s）：坐姿认真听，偶发点头/耳朵微动；转写就绪随时打断进回复
4. 结束：LookAt 缓出，回被打断的动作

## 4. 附录

### 风格 prompt 模板（单一事实来源 `scripts/art-pipeline/style_prompt.txt`）
`3D 低多边形模型搭配细致手工像素风贴图（pixel-art texture），逐像素绘制的色块、像素颗粒清晰、色彩层次丰富精致，复古独立游戏质感（参考《风来之国》《潜水员戴夫》），干净柔和配色`
——禁止临场改词；风格漂移只能改这个文件并经用户确认。（2026-11-25 由"充气粘土"修订为像素风，用户拍板）

### clip 命名约定
`idle_a / idle_b / walk / jump / wave / sit / sleep / petted / held / listen / special_*`（招牌动作）

### 目录
```
scripts/art-pipeline/   style_prompt.txt + 标准化脚本 + README（子 agent 规程）
art/concept/  art/raw/  中间产物（大二进制不进 git）
public/models/          终产物（进 git）
species/                物种配置（进 git）
docs/licenses/          授权凭证（进 git）
```

### 角色边界
美术子 agent 只生产+自检，**不碰工程代码**；主 agent 管接线/实机/归档；
用户管两个人工点 + 红线决策（风格模板变更、付费升级、新物种立项）。

### 风险备忘
- 插件 = Tripo 底层，质量可能不如 Meshy/Rodin：多视图喂图提高下限，兜底 = CC0 底模改造或付费档
- **多视图必须一图一视角**（`--multiview` + 各视角独立文件）：拼版 sheet 只能当人类审阅用，整图喂入 = 每个角色被当成一个视角融合，产出"双面人"畸形（坑 57）
- **生成后先用 `glb_orient_probe.py` 六向深度图自检再入库**：正/背/侧逐张核对，确认只有一张脸、尾巴在脑后；肉眼单张截图判断朝向不可靠（坑 56）
- 插件不做绑骨动画：Blender 是硬依赖，装不上则该物种先降级程序动画
- 工作slop（无人验收的 AI 产出）：每段自检 + 实机验收是强制门，不许跳过
