# 美术资产生产流程（SOP）

> 定稿状态：随 #17 计划生效。本文档是美术子 agent 的"岗位说明书"主干，
> 覆盖四类资产：主角生物 / 场景套件 / 物件道具 / 英雄精修。
> 变更需经用户确认（产品设计文档改动纪律）。

## 0. 总览

```
① 定种      ② 概念稿      ③ 生成网格      ④ 绑骨动画      ⑤ 标准化入库
人写档案  →  出图定风格 →  Tripo插件出模 →  Blender加工  →  检查+配置+实机
(唯一      (唯一强制     (子agent负责,   (子agent负责,   (子agent自检,
 人工点A)   人工点B)      可反复重试)     技术重头)       主agent接线)
```

- **钱**：全程 $0（model3d_generation 插件随 Kimi Work 订阅、Blender 开源、CC0 素材免署名可商用）
- **人**：用户只出场两次——① 定种、② 概念图拍板；其余验收由子 agent 自检 + 主 agent 实机把关
- **周期参考**：主角生物从概念图拍板到实机动起来 2–4 个工作日（④ 占一半）；场景/物件每件半天以内

## 1. 阶段① 定种（人工点A，人写或口述代笔）

产出 `species/<name>.concept.md`，是全链的"需求合同"，后续所有产出对照它验收：

- 这个生物是谁：物种、性格、在收容所里的角色
- 必须保留的外形特征（例：水獭 = 大尾巴、圆脸、前爪灵活）
- 招牌动作清单（物种专属、AI 做不出、须手做的部分，例：搓脸、递贝壳）
- 资产类别与面数预算（查 §3 表）

## 2. 阶段② 概念稿（人工点B，唯一强制看图点）

1. 读 `species/<name>.concept.md` + `scripts/art-pipeline/style_prompt.txt`
   （风格模板单一事实来源：**软低多边形、圆润充气感、粘土质感、无复杂纹理、
   深海水族馆×罗小黑风格、干净柔和配色**，禁止临场改词）
2. image_generation 出概念图；如需多视图生成（推荐），补同角色同姿态的侧面/背面图 1–2 张
3. 交付用户拍板："就这个感觉"或迭代修改。**未经用户确认不得进阶段③**

## 3. 阶段③ 生成网格（子 agent，model3d_generation 插件 / Tripo 底层）

固定参数套路：

- 模型：`--model p2`（四边面拓扑，利于绑骨变形；48–50,000 面区间）
- 面数：`--face-limit N`（预算查下表）
- 纹理：`--no-texture`（裸几何；风格由渲染端卡通着色决定，一律不生成纹理）

| 资产类别 | 面数预算 | ④ 绑骨动画 | 例子 |
|---|---|---|---|
| 主角生物 | ≤1.5 万 | 全做：绑骨 + 重定向 + 手做招牌 | meili 水獭 |
| 场景套件 | ≤2 万/件 | 跳过，静态 | 岩石、珊瑚、水草 |
| 物件道具 | ≤2 千 | 跳过，静态 | 贝壳、信件、明信片 |
| 英雄精修 | 不限 | ④ 全做 + 网格人工精修 | meili 正式版（原型不达标时） |

自检（未过不交付）：多视角渲染预览图，查结构缺陷——缺尾巴/耳朵、多指、比例崩、
与概念图明显不像。小瑕疵用插件 `decimate` / `segment`+`complete` 修；
修不好整只重生成。**可无限重试，无额外费用。** 产出 `art/raw/<name>.glb`。

## 4. 阶段④ 绑骨动画（子 agent，Blender；主角生物才有本阶段）

前置：Blender 官方版（走清华镜像安装，锁版本；Windows 本机无预装，详见 #17 计划风险表）。

1. **绑骨**，三条路线实测择优，判断标准唯一：扭身/扭头时皮肤不塌不裂——
   Blender 插件自动绑 / Mixamo 免费网页上传绑 / Rigify 手绑
2. **挂通用动作**：Quaternius CC0 动作库重定向（idle×2-3 / walk / jump / sit / sleep…；
   与我们同为低模卡通风格，零成本），平台动作库导出 clip 为备选
3. **手做招牌动作**：对照 concept.md 的招牌清单在 Blender 做关键帧——
   全链唯一"纯人工"工序，AI 不可代劳
4. clip 按命名约定落盘：`idle_a / idle_b / jump / wave / sit / sleep / petted / held / listen …`

产出：带骨骼 + 全套动画 clip 的 GLB。

## 5. 阶段⑤ 标准化入库（子 agent 自检 → 主 agent 接线）

**标准化**（`scripts/art-pipeline/standardize.mjs`，gltf-transform）：减面复核 →
剥纹理确认 → 统一朝向/落地高度/比例（主角以 meili 身高为基准 1 单位）→ clip 重排
→ 落 `public/models/<name>.glb`。

**自检**：编辑器插件转台渲染，对照 concept.md 逐项打勾（外形特征、招牌动作、clip 齐全）。

**接线（主 agent，子 agent 不碰工程代码）**：写 `species/<name>.toml`
（模型路径、口癖、倾听参数、动作映射）→ 启动应用实机过交互清单
（唤醒/摸头/拖拽/巡逻/倾听反馈）→ 通过即入库。

**归档**：CC0 素材（动作/底模）及版本日期凭证存 `docs/licenses/`，Steam 发行审计用。

## 6. 质量门与回退路径

| 关卡 | 不通过怎么办 |
|---|---|
| ② 概念图拍板 | 迭代改图，不限次数 |
| ③ 结构自检 | 插件内修 → 重生成 → 仍不行换文生描述重试 |
| ④ 绑骨 deform 不合格 | 换绑骨路线；三路线全败 → 该物种降级"无骨骼程序动画"（整体位移/旋转/LookAt）先上线，记入待办 |
| ⑤ 实机验收 | 回阶段③/④ 定位修；风格漂移回查 style_prompt.txt |

## 7. 角色职责边界

- **美术子 agent**：只负责 §2–§5 的生产与自检，产物为文件 + 预览图，**不碰仓库工程代码**；
- **主 agent**：定种代笔、概念图传话、species 配置与前端接线、实机验收、凭证归档；
- **用户**：人工点A（定种）、人工点B（看图拍板），以及所有红线决策（风格模板变更、
  付费档升级、物种新增立项）。
